# Gold Tracker

بوت Telegram لمراقبة الذهب والفضة وأسعار الصرف، مع تقارير دورية وتنبيهات لا تتكرر إلا عند عبور السعر المستهدف.

## ما الذي يراقبه؟

- أوقية الذهب والفضة بالدولار.
- جرام الذهب 24 و21 في دبي.
- تقدير حسابي لجرام الذهب 24 و21 والفضة في مصر.
- الدولار والدرهم والريال مقابل الجنيه المصري.
- مقارنة تقديرية لسعر عيار 24 بين مصر ودبي.

> أسعار مصر تقديرات حسابية مبنية على السعر العالمي والصرف وعلاوة محلية قابلة للتعديل، وليست سعر بيع مباشرًا من سوق الصاغة.

## التشغيل الآلي

يفحص GitHub Actions الأسعار كل 30 دقيقة تقريبًا. يرسل تقريرين يوميًا وفق `REPORT_HOURS_UTC`، ويرسل تنبيهًا فور عبور أحد الأهداف. لا يكرر التنبيه أثناء بقاء السعر تحت الهدف، والتشغيل اليدوي يرسل تقريرًا فوريًا.

## الإعداد

أضف إلى GitHub Actions Secrets:

- `TELEGRAM_TOKEN`
- `CHAT_ID`

يمكن تعديل الأهداف من ملف `.github/workflows/main.yml`:

- `GOLD_OZ_ALERT_USD`
- `UAE_24_ALERT_AED`
- `EGY_21_ALERT_EGP`
- `LOCAL_EGYPT_PREMIUM_EGP`
- `REPORT_HOURS_UTC`

## التشغيل محليًا

```bash
python -m pip install -r requirements.txt
TELEGRAM_TOKEN=... CHAT_ID=... FORCE_REPORT=true python gold_bot.py
```

المصادر الحالية: `gold-api.com` للمعادن و`open.er-api.com` للصرف.
