# تشخيص البشرة الذكي (Skin Diagnosis App)

تطبيق ويب بسيط (HTML/CSS/JS بدون أي أدوات بناء) يوجّه المستخدم عبر سلسلة أسئلة مباشرة
لتحديد نوع بشرته والمشاكل التي يعاني منها (حب الشباب، الرؤوس السوداء، الهالات السوداء،
المسام الواسعة، التجاعيد، التصبغات، الجفاف، الاحمرار، بهتان البشرة)، ثم يعرض في النهاية
تقريرًا تحليليًا تفصيليًا يشمل:

- نوع البشرة والأسباب المحتملة لكل مشكلة مكتشفة
- مكونات تجميلية فعّالة يُنصح بالبحث عنها في المنتجات
- وصفات ونصائح طبيعية عامة
- روتين عناية يومي (صباحي/مسائي) وروتين أسبوعي
- تنبيهات تلقائية توصي بمتابعة أخصائي جلدية أو صيدلي عند الحالات الشديدة أو الحمل/الرضاعة
  أو التداخل مع علاج طبي حالي

التطبيق ثنائي اللغة بالكامل (عربي/إنجليزي) عبر زر تبديل اللغة في أعلى الصفحة — الأسئلة،
قاعدة المعرفة، والتقرير النهائي كلها تُترجم فورًا دون فقدان الإجابات المُدخلة، ويُحفظ
اختيار اللغة في المتصفح (localStorage) للزيارات القادمة.

## هيكل المشروع

```
skin-diagnosis-app/
├── index.html          # هيكل الصفحة (شاشة ترحيب، أسئلة، تحميل، نتيجة)
├── css/style.css        # التصميم (متجاوب، RTL/LTR)
└── js/
    ├── i18n.js           # نصوص الواجهة الثابتة بالعربية والإنجليزية
    ├── questions.js     # شجرة الأسئلة الأساسية وأسئلة المتابعة لكل مشكلة (ثنائية اللغة)
    ├── knowledge.js      # قاعدة المعرفة: تحليل كل مشكلة (أسباب/مكونات/وصفات/شدة) بلغتين
    └── app.js            # محرك الاستبيان، تبديل اللغة، وبناء التقرير النهائي
```

## التشغيل محليًا

لا يحتاج المشروع أي تثبيت أو بناء، فقط قدّمه كملفات ثابتة:

```bash
cd skin-diagnosis-app
python3 -m http.server 8000
# افتح http://localhost:8000 في المتصفح
```

## التسعير المعروض في التطبيق

- **٢٠$** — التحليل الرقمي الشامل (التقرير التفصيلي الذي يعرضه التطبيق نفسه).
- **١٠٠$** — كشف مباشر مع أخصائي جلدية أو صيدلي (نموذج حجز بسيط داخل شاشة النتيجة).

> ملاحظة: التسعير معروض حاليًا كواجهة عرض فقط (Front-end). نموذج حجز الكشف يعرض رسالة
> تأكيد داخل الصفحة ولا يرسل بيانات فعليًا. لتفعيل الدفع الإلكتروني الحقيقي (مثل Stripe
> أو PayPal) أو إرسال طلبات الحجز لبريد/قاعدة بيانات فعلية، يلزم إضافة خادم خلفي (Backend)
> ودمج بوابة دفع، وهو خارج نطاق هذا الإصدار الأولي.

## إخلاء مسؤولية

هذا التطبيق أداة إرشادية عامة لأغراض تجميلية وليست بديلاً عن التشخيص أو الاستشارة الطبية
المتخصصة، خصوصًا في الحالات الشديدة أو المزمنة أو أثناء الحمل والرضاعة أو عند وجود علاج
طبي حالي.
